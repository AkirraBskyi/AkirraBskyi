### About me

I build **ML-powered trading systems** — from signal generation and model training to backtesting and live execution on MetaTrader 5.

Currently focused on:
- **HMM + XGBoost filter** — hidden Markov models for regime detection, per-symbol signal filtering
- **Systematic backtesting** — vectorised engines with realistic slippage and spread modelling
- **Feature engineering** — tick data, order flow, macro indicators
